Personal portfolio website developed for CPIT405 – Internet Applications at King Abdulaziz University.
About the Website
This responsive website introduces my academic background, technical skills, practical experience, certifications, and selected projects. It also provides access to my CPIT405 laboratory assignments and a contact page.
Website Pages
- Home (index.html): Introduction, About Me, education, technical skills, Saudi Aramco training experience, certifications, and featured projects.
- Labs (labs.html): Links to completed CPIT405 Labs 1, 2, 3, 5, 6, and 7.
- Contact (contact.html): Contact information, GitHub and LinkedIn links, and a message form.
 Projects
- VIVID: Graduation project exploring Saudi cultural heritage through location-based mixed reality.
- Onboarding Website: Departmental onboarding resources developed during Saudi Aramco training.
- AI Travel Mate: Travel-planning app UI/UX prototype created in Figma.
- Vulnerability Dashboard: Improvements to an existing Flask dashboard during training.
Technologies Used
- HTML5
- CSS3, including responsive layouts and media queries
- JavaScript for interactive laboratory exercises
- DOM manipulation, events, cookies, XMLHttpRequest, and Fetch API in the labs
